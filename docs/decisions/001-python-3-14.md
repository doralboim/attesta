# ADR-001: Python 3.14

**Status:** Accepted (2026-07-05)

**Context:** Architecture doc specifies Python 3.12. User requires Python 3.14 + FastAPI.

**Decision:** Pin `requires-python = ">=3.14"` in pyproject.toml. CI uses Python 3.14. Docker base image `python:3.14-slim`.

**Consequences:** Developers need Homebrew/pyenv 3.14+. Ecosystem packages (mypy, pgvector) may lag; CI uses `continue-on-error` on mypy until stubs stabilize.
